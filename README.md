# ZKIR Explorer for VS Code

Inspect and compare Midnight ZKIR circuits using the native VS Code sidebar and editor. Run **ZKIR Explorer: Open Baseline** from the Command Palette, or right-click a `.zkir` file and choose **Open as Baseline**. Expand **Instructions** in the ZKIR Explorer activity bar; expand an instruction to inspect its operands and connections directly, or select it to open an interactive dependency view. Click connected instructions to follow data flow; see constants and variables in the operand list, or expand the raw instruction. Run **ZKIR Explorer: Compare with Candidate** to choose another file and open a comparison report.

Run **ZKIR Explorer: Load Example Baseline** to open a small artifact generated by Compact 0.36.1. To compare it with the second artifact, use **Compare with Candidate** and select `public/examples/changed.zkir` from the project. Their Compact sources are in `examples/source` in the project. The example was compiled with `--skip-zk`; no keys or proofs were generated.

The experimental structural decoder supports selected ZKIR 2.0, 3.0 and 3.1 instructions; unknown operations and unresolved identifiers trigger warnings. It is not the official Ledger type checker or a proof verifier. Counts do not measure proof cost, and instruction differences do not establish semantic changes. Source-line mapping and proof-failure diagnosis are not implemented. Files are read locally.

For development, run `npm install`, `npm test`, and `npm run package` to create a VSIX file.
